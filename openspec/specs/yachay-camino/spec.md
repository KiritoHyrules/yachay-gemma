# yachay-camino Specification

> NEW capability: visual progress map displaying mastery across the curriculum

## Purpose

Let students see their learning journey — which topics they've conquered and what lies ahead — reinforcing motivation through visible progress (N-03, N-06).

## Requirements

### Requirement: Progress Map Screen

The system SHALL display a scrollable list of all curriculum subtopics from `obtener_plan_completo()`, each with a mastery percentage bar and colored status indicator. The screen MUST be accessible via the Camino tab in bottom navigation.

#### Scenario: Screen loads with mastery data

- GIVEN the student taps the Camino tab
- WHEN the progress map renders
- THEN every subtopic from the curriculum MUST appear
- AND each MUST show a horizontal progress bar with percentage

### Requirement: Mastery Color Coding

Each topic SHALL be color-coded by mastery level:

| Color | Threshold | Meaning |
|-------|-----------|---------|
| Green | P(L) ≥ 90% | Dominado |
| Yellow | 40% ≤ P(L) < 90% | En progreso |
| White | P(L) < 40% | No iniciado |
| Gray (lock icon) | Prerequisites unmet | Bloqueado |

#### Scenario: Color states render correctly

- GIVEN topics with P(L)=0.95 (mastered), P(L)=0.60 (in progress), P(L)=0.10 (started), and a locked topic
- WHEN the progress map renders
- THEN the mastered topic MUST display green bar
- AND the in-progress topic MUST display yellow bar
- AND the low-progress topic MUST display white bar
- AND the locked topic MUST display gray with lock icon

### Requirement: Yachay's Progress Note

Each topic card SHALL display a personalized note generated by the tool `generar_nota_progreso(tema)`. The note MUST be stored with the topic and refreshed when mastery updates.

#### Scenario: Note reflects current state

- GIVEN `arit_nn_01a` has P(L)=0.60
- WHEN `generar_nota_progreso("arit_nn_01a")` is called
- THEN Yachay's note MUST be stored and displayed on the topic card
- AND the note SHOULD encourage the student ("¡Vas por buen camino! Te falta poco para dominar Valor Posicional.")

### Requirement: Mastered Topic Celebration

Tapping a mastered (green) topic SHALL show a celebration dialog with Yachay's congratulatory message and a summary of the student's journey on that topic (attempts, time spent).

#### Scenario: Student taps mastered topic

- GIVEN `arit_nn_01a` is marked as mastered
- WHEN the student taps the topic card
- THEN a dialog MUST appear showing Yachay's celebration message
- AND the dialog MUST display stats: total attempts, time spent
- AND the dialog MUST include a "Continuar" button to dismiss

### Requirement: Locked Topic Behavior

Tapping a locked topic SHALL display a tooltip or snackbar explaining which prerequisites must be completed first, without revealing the locked topic's content.

#### Scenario: Student taps locked topic

- GIVEN `arit_of_02` requires `arit_nn_01` which is not mastered
- WHEN the student taps the locked topic card
- THEN the system MUST display which prerequisite is missing
- AND MUST NOT navigate to or reveal the locked topic's content
