# yachay-perfil Specification

> NEW capability: student profile screen with Yachay's personalized insights

## Purpose

Give the student a personal space showing their identity, stats, and what Yachay has learned about them — building trust through transparency (N-03).

## Requirements

### Requirement: Profile Screen

The system SHALL display a student profile screen accessible via the Perfil tab in bottom navigation. The screen MUST show: avatar (default illustration), student name, grade level, and three stat cards (total time, ejercicios completados, precisión).

#### Scenario: Profile loads with student data

- GIVEN the student taps the Perfil tab
- WHEN the profile screen renders
- THEN the avatar, name, and grade MUST display from `StudentState`
- AND stat cards MUST show accurate, calculated values from `interaction_log`

### Requirement: "Lo que Yachay sabe de vos"

The screen SHALL display a section titled "Lo que Yachay sabe de vos" containing a personalized paragraph generated by tool `generar_resumen_alumno()`. This paragraph MUST be regenerated when significant events occur (topic mastered, diagnostic completed) and cached locally.

#### Scenario: Summary generated for student

- GIVEN the student has completed 15 exercises and mastered 3 topics
- WHEN `generar_resumen_alumno()` is called
- THEN it MUST return a warm, personalized paragraph in Peruvian Spanish
- AND the text MUST reference specific mastered topics by name
- AND the text MUST include an encouraging next-step suggestion

#### Scenario: Summary updates after milestone

- GIVEN a cached summary exists from when student had 2 mastered topics
- WHEN the student masters a third topic
- THEN the summary MUST be regenerated on next Perfil tab visit
- AND the new summary MUST reflect 3 mastered topics

### Requirement: Achievements List

The profile screen SHALL display a scrollable achievements list. Achievements SHALL be unlocked based on deterministic rules (not Gemma-generated): first exercise completed (Primer Paso), first topic mastered (¡Dominado!), 10 correct in a row (Racha Perfecta), all prerequisites cleared for a competency (Sin Barreras).

#### Scenario: Achievements display

- GIVEN the student has completed first exercise and mastered one topic
- WHEN the profile screen renders
- THEN "Primer Paso" and "¡Dominado!" achievements MUST display as unlocked
- AND unearned achievements MUST display as locked (grayed out)

#### Scenario: New achievement triggers notification

- GIVEN the student just achieved 10 consecutive correct answers
- WHEN the dispatch loop detects the milestone
- THEN Yachay MUST congratulate the student in chat
- AND the achievement MUST appear unlocked on next Perfil visit
